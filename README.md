# CRAZYSHOOT

版本 **0.18.1**。浏览器步兵与装甲占点游戏，4v4–12v12，单人 AI 或房主权威联机。

比赛从 0 分开始，守点与击杀得分，先到 1000 分获胜；常规图 10 分钟、法老图 20 分钟（房主可在房间内自定义 1–60 分钟）到时比较积分，相同为平局。必要资源、碰撞、角色和图形预热完成后才进入整备，联机等待各端准备完成。阵亡后重新部署有 5 秒无敌保护，受保护角色会泛金光。

地图采用接近现实的军事材质、1m全方块构造与32×32/64×64/128×128像素贴图；方块材质按 Minecraft 规则严格最近邻放大，近看每个纹素都是棱角分明的纯色方块，弹孔贴花仍保留照片式真实形状。保留原精美天空盒。四图新增有明确用途的高台、缓坡、坑洞与战术掩体；所有实体地图表面与碰撞共享同一体素格。

坑洞设有坡道和贴墙梯子：面向梯子，前进键爬上、后退键爬下，跳跃键中途离开。离开战区显示6秒返回提示，采用安全恢复，不设坐标空气墙。

所有非 `open` 建筑默认整栋可进入：南北长墙开 4 m×3 m 门洞（贴邻建筑改侧门），四面墙开 2 m×2 m 窗洞；净高 ≥8 m 自动生成二层，配 2 m 宽、4 级 1 m 楼梯。室内按建筑类型布置家具，rug/墙饰是不碰撞的薄片。7 张 64px 室内材质在 `public/textures/interiors/`，其中 plaster / concrete-floor / wood-planks 同时作为 68–70 号体素材质。布局、内饰分类与数据契约见 [地图设计](docs/MAP_DESIGN.md)。

## 本地运行

```bash
npm install
node server/signal/server.mjs
# 另一个终端
npm run dev -- --host 127.0.0.1 --port 5174
```

打开 `http://127.0.0.1:5174/game.html`。默认窗口模式，可在大厅选择全屏。低配默认内部降采样、无抗锯齿，帧率默认不限，HUD 保持原分辨率；J1900 尚未真机验收。

同一局域网内，把上面的 Vite 启动参数改为 `--host 0.0.0.0 --port 5174`，其他电脑打开 `http://<运行服务的电脑的局域网 IP>:5174/game.html`。房主创建房间后，把四位数字房间码告诉其他玩家，开局时自动补齐 AI。局域网内的 WebSocket 中继走运行信令服务的电脑。

步兵：WASD 移动、Shift 疾跑、Space 跳、按住 Ctrl 静步、C 切换蹲姿、按住 Q/E 左右歪头（同时按回正，开镜可用）、R 换弹、B 切换射击模式、E 上下车、G/H 投掷、Tab 整备或阵亡换装、N 静音。蹲下或趴下时按空格先起身、站起来后再按才跳；趴下时移动与开镜/射击不能同时进行，谁先开始谁生效。设置中可调整灵敏度、瞄准方式、FOV、音量和帧率。

深水中按住 Space 上浮、Ctrl 下潜、Shift 快游。朝与水面齐平的低岸游即可直接上岸，高池沿可以朝岸游并按住 Space 攀上去。不划水时头部保持在水面上，划水时会慢慢浮高一些。

坦克：W/S 纵向驱动，A/D 转动车体；鼠标独立操作炮塔和炮管。倒车转向使用实际车速，履带车可以原地转向。数字键换座，B 切 AP/HE。中央标记是期望方向，金色圆环是实炮方向，青色菱形是有解时的预计落点。射击始终取真实炮口，炮塔未追上时不会自动纠偏。载具武器带散布：30mm 机关炮首发 ±0.05°、每发累积 +0.012°（上限 ±0.25°），停火 0.8 秒后回落，可连续射击；120mm 主炮固定 ±0.03°；载具机枪 ±0.15° 起累积到 ±0.6°。30mm AP 按装甲分档（轻甲 0.40 / 中甲 0.18 / 重甲 0.13），对主战坦克正面持续命中约 25 秒可击毁；AI 乘员使用自己的瞄准误差，不再叠加武器散布。

载具生存性：摩托与吉普属于非装甲目标，普通步枪每发约 3 点伤害（5.56 打爆吉普约 60 枪），装甲车挨普通子弹只有 2.5%。血量低于 35% 开始冒灰烟、低于 15% 转浓黑烟并带火星，联机双方都看得见；被击毁时爆炸并对 7.5m 内的步兵与其他载具造成范围伤害，车体变成全黑残骸留在原地，下一局自动重置。车速较高时中途下车会受与车速挂钩的摔落伤害（5 m/s 起，上限 85）。

基地与完整控制的据点附近，静止可恢复生命及备用弹药；基地附近的静止车辆可维修和补炮弹。子弹打在墙、地面和车体上会扬起按材质配色的灰尘；静态表面留下 0.3m 弹孔贴花（含裂纹与焦痕，10 秒后淡出消失），混凝土、金属、木材、泥土各有撞击声。房主权威命中通过 `impactFx` 实时广播，同房间所有客机看到同一批弹着点。

手雷与烟雾已接入。四张图在蓝、橙两侧各放一个 AMR 与一个火箭筒点位（船坞、花园另有喷火器），走近按 E 拾取，每局开始全部重置、先到先得：AMR 5 发无备弹、任意部位一击致命，对装甲车/步战车 3 枪、轻坦 5 枪、主战坦克 7 枪；火箭筒 3 发慢速火箭，直击重创所有载具（主战约 3 发）并带 9m 爆炸范围伤害；喷火器 100 燃料、喷时快速下降，只伤人不伤车，敞篷的摩托/吉普乘员会被直接烧到，燃料耗尽或阵亡自动换回主武器。机器人按角色配枪（每队栓狙、连狙、步枪、冲锋枪、可选机枪），复活按队伍缺口和敌人威胁换枪；约三分之一走侧翼绕后，狙击手在外围架枪，交火会蹲/趴/跳，过开阔地会扔烟、清掩体会扔雷且先检查队友位置。燃烧弹与固定机枪尚未开放。

## 验证

```bash
npm run build
npm test
npx vitest run tests/building-interiors.test.ts tests/interior-assets.test.ts # 四图门/室内/楼梯实走 + 室内材质清单
npm run test:water        # 扫描水体漏口、AI 离水路线并模拟出水
npm run test:audit        # 先启动上面的 Vite 与信令服务
npx tsx tools/game/audit/lan-controls.ts # 多浏览器键鼠、互伤和输入丢包回归
npx tsx tools/game/audit/bullet-impact-check.ts # 弹着灰尘/弹孔、10秒消失与联机同步
npx tsx tools/game/audit/lean-stance-check.ts  # 像素过滤、歪头落点与趴下互斥
npx tsx tools/game/audit/lean-net-check.ts      # 歪头动作联机同步
npx tsx tools/game/audit/bot-strategy-check.ts  # AI 配枪、拉侧、战术动作与投掷
npm run test:vehicles     # 坦克验收及录像；本机 ffmpeg
npm run test:performance  # 四地图 × 8v8/12v12 × 每段60秒
```

本轮浏览器与录像脚本按macOS审计环境运行；浏览器检查可用 `CRAZYSHOOT_CHROMIUM` 指定 Chromium，其他系统须配置相应 Chromium/ffmpeg 路径。验收数据、修复状态和未完成项见 [本轮交付清单](docs/audit-2026-11-06/DELIVERY.md)，性能边界见 [性能说明](docs/PERFORMANCE.md)；弹着点实测见 [弹着点验收](docs/impacts-2026-11-08/REPORT.md)，像素/歪头/姿态见 [像素与歪头验收](docs/pixel-lean-2026-11-08/REPORT.md)，AI 见 [AI 策略验收](docs/ai-strategy-2026-11-08/REPORT.md)。32/64材质与生成提示词见 [材质包说明](public/textures/battlefield-v1/README.md)；地图/梯子专项验收见 `docs/audit-2026-11-06/map-design.json`，实际爬梯录像见同目录 `ladder-climb.webm`。原始源码压缩包和审计证据保存在 `docs/audit-2026-11-06/`。

## 目录

- `src/game/core`：加载、输入、设置、固定模拟时钟与资源释放。
- `src/game/combat`：弹种、弹体池、载具武器散布、投掷物及烟雾。
- `src/game/world`：后台地形生成、碰撞查询、导航、合批和贴地阴影；可进入建筑的门窗/楼板/楼梯、家具与室内装饰。
- `src/game/vehicles`：车体坐标、炮塔轴控制、载具伤害分档与低血/爆炸/残骸特效。
- `src/network`：信令、可靠事件与可丢弃状态通道。
- `src/maps`、`src/content`：地图与装备数据。
- `tools/game/audit`、`tests`：本轮行为回归与性能采样。

部署说明见 `deploy/README.md`；本次上线记录与公网验收见 [发布记录](docs/deploy-2026-11-09/REPORT.md)。
