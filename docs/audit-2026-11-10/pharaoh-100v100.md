# 法老坟墓 100v100 · 本机可玩性采样

- 版本：0.20.2 / BUILD_ID `bddc712ac7882b1a`
- 硬件：Apple M5 Pro / Chrome headless，1280×720、quality=low、res=64、60 fps 上限
- 场景：法老图，每侧 100（199 AI + 本机），真实 host、真实控制器/枪弹/载具
- 采样：15 s，`simulate` 900 次（60/s），`renderFrame` 897 次

| 指标 | 数值 |
|---|---:|
| sim step p50 / p95 / p99 | **6.2 / 7.5 / 13.7 ms** |
| renderFrame p50 / p95 | 2.7 / 3.3 ms |
| 实际 tick | 60/s（900/15s） |
| 渲染 | 60 fps，draw calls ≈312，tris ≈1.18M |
| 100v100 优化前 | sim p95 **62.7 ms**，大量掉帧 |

## 优化内容

1. **团队/分组目标**：大房不再每 Bot 对 7 个据点跑 `routeSteps`；每队 3 组共享目标，字段数从最多 200 个降到 ≤6 个。
2. **AI LOD**：非战斗 Bot 0.9–1.4 s 才决策一次，交火 5–6 Hz；小房仍 8 Hz。
3. **高级决策裁剪**：大房非战斗跳过 flank/hunt/hold/detour/stance/smoke/frag；交火保留瞄准/首发精度/基本姿态。
4. **视距收紧**：普通 120 m、机枪 180 m、精确射手 300 m、狙击 360 m（并与武器射程取小）；不再全图索敌。
5. **渲染全实体但远距 LOD**：取消玩家 550 m 和载具 360/420 m 的隐藏裁剪；>220 m 角色只摆位置不跑骨骼动画；所有在视锥内的实体仍渲染。
6. **出生分散**：100 Bot 按黄金角铺开 8–46 m，并按三路目标推进，避免全部挤在出生点。

## 如实说明

- 100v100 的 sim p95 仍高于 8v8（约 7.5 vs 3.7 ms），并非“完全不变”；但已从 62.7 ms 降到 7.5 ms，60 FPS 稳定，p99 13.7 ms。
- 大房 AI 的高级战术被有意降级；狙击仍保留 360 m 视距、首发精度和弹道补偿，交火有基本准度。
- 未在 4× CPU 节流或低端机验收 100v100。
