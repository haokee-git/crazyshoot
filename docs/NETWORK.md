# LAN 同步 / 主机权威

## 0.12.0 当前实现
- 主机权威：移动 / 跳跃 / 下蹲 / 伤害 / 计分 / 占点 / 载具 / 复活。
- 20Hz `snap`；客机平滑跟位；客机只发输入、射击与载具输入。
- **P2P 失败自动中继**：WebRTC DataChannel 未建立时，游戏消息走 `/signal` WebSocket 中继（服务器只转发，不跑逻辑）；每 50ms 一次，满 24 人时主机对无 P2P 的客机广播一次中继消息。
- 开局同步：房主把地图、`4–12` 房间规格、整备秒数写入 `start` 消息；客机先改 URL 再建场景，避免主客地图/人数不一致。
- 客机载具：客机发 `veh` / `vehInput` / `vehFire`，主机移动载具并回传位置/炮塔角；客机不本地模拟载具。
- 客机复活点：客机发 `respawn` / `respawnNow`，主机按选择点复活。
- 联机前界面：`start` 重发 40 次（10s）；房主随时可开局，客机进房后走 P2P 或中继。

## 当前（2 人验证）
- 客机不再本地跑物理：只本地处理鼠标视角，发送按键 + yaw/pitch。
- 主机用 `NetworkInput` 驱动客机的 `PlayerController`，权威位置/跳跃/下蹲/碰撞。
- 主机 20Hz 下发 `snap`：主机状态 + 客机权威状态；客机平滑跟位，主机端客机角色由权威控制器驱动。
- 命中/计分仍由主机裁定；客机只发送射击 origin/dir。
- 移动起步/刹车响应已调快，避免松键后滑行数米。
