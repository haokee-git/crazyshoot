# 0.15.1 材质、分划与M16后坐力调整

实际生产构建 `7c5fc765ac3ee191`，材质版本4。本地预览端口5175，尚未发布线上。

| 问题详情 | 截图／录像 | 已实施解决方案 |
|---|---|---|
| 64/128材质主要只是碎点密度变化，主轮廓仍锁在32像素格上 | [四类细节对比](detail-tiers.png)、[九类材质](material-tiers.png) | 去掉“每隔2/4像素必须等于32档”的错误约束，取消细节图转换成±18明暗碎点的做法。64/128直接按各自网格采样已经绘制的细节参考，保留细裂缝、叶脉、木纹、划痕、颗粒轮廓；采用16/24色限定色板，32档继续保留原有12色设计。不是锐化或放大，不增加运行时滤镜。 |
| 倍镜刻度偏粗、中心也是暗色 | [全部瞄具对照](optics.html) | 光学镜主线及刻度物理宽度缩小约36%/46%，重新控制屏幕像素抗锯齿覆盖；中心独立红色小点，不把整条刻度染红。红点/全息保留原来分划，镜外保持清晰画面。 |
| 6倍、8倍实际放大差距过小 | [6倍](optics/6x.png)、[8倍](optics/8x.png) | 移除最低9度FOV限制，以透视投影的正切关系计算倍率。1x视角55度，6x约9.917度，8x约7.446度，保证实际放大比例。仍使用单次世界渲染。 |
| M16每枪突跳后等速指数回落，横向反馈不足 | [瞄具和射击录像](optics-and-m16.webm)、[实测轨迹](validation.json) | 相机改为阻尼弹簧冲量，开枪先改变速度，再连续抬起与回弹；短段相关横向偏移配合逐发变化，不固定左右交替。M16垂直参数从0.32降至0.27，水平从0.16提高至0.29，保留温和上抬。 |
| 枪身只有统一的后移，没有受力与回弹层次 | 同上录像 | 枪身增加独立后移、俯仰、偏航、滚转响应，逐发冲量不同。腰射能看到枪口抬起及侧摆；完全ADS时角度后坐力由相机和弹道共同承担，枪身主要前后回弹，避免另一个视觉转角造成红点与落点脱节。 |

材质使用既有细节母版 `art/materials-v3/detail128`，修复的是导出路径；本轮没有再次生成素材。新成品位于 `public/textures/battlefield-v4/{32,64,128}`，旧v3文件及旧证据保留。导出工具 `tools/round2/export-pixel-materials.py`；各档4×4平铺预览在v4的 `masters` 目录。高档不再承诺逐像素对应低档网格，而保持同一材质构图与配色。

本轮验证：48项单元测试通过；8种瞄具同一M16、位置与朝向截图；10次真实输入三连发共30发，无页面或帧循环错误；13项主客机回归通过。样例中ADS最大上抬约0.335度，水平范围约−0.188至+0.109度，停火后正常回正。这是一次受控样例，不是全部随机序列的最大值。

截图包括机械、红点、全息、2x、3x、4x、6x、8x；6x和8x均按最高倍率展示。点击对照页中的图片可看1280×720原图。录像使用真实输入，位置和装备通过调试接口布置。

未重新执行上一轮完整四图性能压测；这次保持纹理数组尺寸、世界渲染次数及模型数量，后坐力只增加少量标量计算，没有增加后处理。仍未取得J1900真机，不宣称目标机性能达标。动作是否达到你期望的手感，以本地实际试玩为准，不能只凭测试通过判断。
