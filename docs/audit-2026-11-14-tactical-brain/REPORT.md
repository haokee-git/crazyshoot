# 战术决策与退化验收 — 0.20.10

日期：2026-11-14；版本 `0.20.10`，BUILD_ID `7867408bd6239fa6`。设计说明见 `../AI_TACTICS.md`（仓库 `docs/AI_TACTICS.md`）。

## 实现范围

- 感知与衰减记忆：敌人需先被看见；共享观察报告，按车辆去重。战略层不读取未观察敌人的实时坐标。
- 目标效用：占点、中线价值、防守压力、友军分工、近期损失、路线可行性、车况与实际弹药共同参与判断；进攻不是唯一可选项，安全的家点也不会仅因距离近无限胜出。
- 局部战术：推进、突击、侧击、架枪、脱离、重新接敌，保留行为承诺与切换门槛。近点有优势时会加大夺点权重；远枪被贴近会脱离，伤重/断弹会回补给。
- 走位与执行：在真实支撑与碰撞中检查候选位置；保留原有导航、水体与脱困。修正换弹时无条件停步、低姿态撤掉按键但仍被 worldMove 带出掩体的问题。导航明确要求高处时可用真实翻越检查处理入口高差。
- 载具协同：保持车距、有限等待和友车绕行；小据点可选择不阻挡友军通道的停车位置。近距离有真实射界时坦克可以稳车交战，有近期实际开火记录/装填进度才持续停留；空弹、无射界不能用“交战”掩盖卡住。
- 火控：观察速度提前量、身体/露头感知、目标价值、武器/距离/运动/弹药决定节奏；保留原反应延迟、弹道、枪口与射速限制。友军挡枪会停火换角，普通枪械不向封闭装甲乘员浪费射击。30 mm 与 120 mm 使用各自弹道。
