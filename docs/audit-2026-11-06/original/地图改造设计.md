# CRAZYSHOOT 四图改造设计

这是后续agent可采用的功能布局草案，尚未写入游戏，也未做对战平衡验证。图中坐标以左上为(0,0)，右为+x，下为+z；300×300米。阵营位置按图定义，不假定原项目的方向已经一致。数据见map-designs.json，矢量源见design-*.svg。

## 统一设计约束

- 从真实用途推导地形：港池有岸线/高程，河谷有河床/河面/桥面，庄园有平台/排水，机场有平整跑道/服务道。先定高程表和可达路线，再做噪声与装饰。
- 主要车辆通路8–12m，关键路口留足转弯扫掠空间；优先小于约10–12度连续坡，局部上限需按车型验证。步兵侧道2–4m，短阶梯要有可达替代路线。
- 地面为连续低模曲面，禁止用到处1m台阶表达所有坡度。基础可用4m采样网格，关键路缘/战斗掩体处1–2m局部加密；32m左右区块与多档LOD，碰撞和导航同源。
- 高点必须有背坡进攻/侧翼反制，不能同时看穿两个基地和三个点。每15–25m考虑一次可用转移掩护；“有掩体”按真实站姿/蹲姿/枪线验证。
- 基地至家点初始目标12–18秒、中央首轮接敌20–28秒是设计目标，不是当前测量结果；双方等价目标到达时间差尽量控制在约10%内，按实测调整。
- 每个据点至少2个不共线入口，中心点至少3条步兵进路；桥/浅滩/楼梯都须真正参与碰撞与导航。AI使用同一通路，不能因直线走不到而额外传送。
- 只做2–4栋关键可进入建筑，入口有视觉线索；装饰建筑明确不可进入。室内暗部用烘焙/顶点色，不堆实时光。
- 假车位方块、重复据点环、无效拾取箱和开发标签不进入正式地图。每个设施有功能或纯装饰的明确语义。
- 场景预算优先遵守总Prompt的J1900目标：分块合批、共享材质、低频纹理、远景剪影、少量贴地阴影。地形丰富不等于增加独立Mesh数量。

## 分批落地与验收

先做船坞一张低模灰盒，验证枪战/车战/AI路径和性能结构，再复制规则到其余地图。每图交付：统一高程表、地形网格、低成本碰撞、导航数据、关键出生/据点/车辆位置、材质清单、分块统计、固定路线帧时间和同视角截图。

图中建筑和掩体只表达关键分区；不应机械照搬为最终精确施工坐标。修复agent必须先跑可达性和视线检查、调整局部冲突，再完善装饰。不可把示意图当已经完成的地图实现。
