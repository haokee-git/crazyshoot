# 红点样式核对与调整

当前本地构建：0.15.1 / d75ea74fbc4360b3。

选用的红点视觉参考：

- [PUBG 实机画面：Eurogamer](https://www.eurogamer.pt/battlegrounds-como-desbloquear-modo-primeira-pessoa)。人工查看图像确认是开放式红点：扁顶、圆弧侧边、较薄镜框、单独中心红点。搜索结果的自动图片说明曾将另一张全息图误标为红点，已排除该图作为红点参考。
- [C-MORE Railway 官方产品页](https://cmore.com/Item/CRW)：圆弧薄框、开放镜片、低矮长底座及后部组件的现实参考；厂商标注29mm玻璃镜片。游戏模型只借鉴轮廓和构件关系，经过第一人称视野适配，并非逐毫米复制实物。

本地改动：红点从厚矩形罩改为扁顶圆弧的开放式薄框；窗口宽度参数从0.064改为0.052，镜框约0.0023，低矮长底座。独立镜片裁切匹配新轮廓。同步修改权威枪口阻挡计算使用的瞄具位置。

先前反馈的全息窗口偏小也已调整：较大的矩形罩，窗口宽高0.088×0.067，观察距离0.255，保持与红点不同的轮廓。现实全息外观参考[厂商 EOTECH EXPS3](https://www.eotechinc.com/products/eotech-hws-exps3)，未把它作为红点参考。

倍镜刻度在此前过细版本与原版之间折中：主线最小约1.7输出像素，刻度约1.6；中心红点保留。此处没有新增全屏渲染或模糊。

验证：11枪×红点/全息共22组实际浏览器ADS，全部对中，最大投影偏差约1.6e-8像素，第一人称最大5842三角形；无页面异常，生产构建通过。原始数据见 `validation.json`。

当前游戏截图：[红点ADS](red_dot-ads.png)、[红点腰射](red_dot-hip.png)、[全息ADS](holo-ads.png)。参考网页截图只供核对，没有作为游戏素材使用。

## PUBG轮廓修订

用户否定接近圆环的版本后，红点改用PUBG实机轮廓：宽平顶、斜肩、短侧边、向下收窄的底部。镜框和镜片共享轮廓定义，不再使用圆或椭圆裁切。圆环版本截图保留在 `red_dot-circle-ads.png`；当前图为 `red_dot-ads.png`。最终构建身份与11枪对中结果见 `pubg-outline-validation.json`。
