# 0.14.0 性能与验收边界

2026-11-07，Asia/Shanghai。当前版本为写实军事材质、1m全方块地图、实际32/64像素纹理，保留原天空盒。旧连续地表版本数据归档在 `audit-2026-11-06/previous-continuous/`，不作为本版成绩。

本轮浏览器环境沿用原审计的Apple M5 Pro / 24GB，本地Chromium。**没有J1900真机帧率或硬件WebGL2通过结论**；旧核显、DDR3、4GB压力、GPU计时与进程工作集未测。

## 工程结构

- Worker生成完整体素占用格、可见面的贪心合并网格、实际可通行边和导航数据，再Transferable传回。加载页持续显示真实阶段/完成项。
- 1m方块按64m区块合面，保留独立区块剔除。体素的渲染、地表支撑、身体碰撞和战斗DDA使用同一份数据；不递归扫描美术场景。
- 56类材质都有实际32×32与64×64 PNG，运行时合为单图集；低饱和真实材质变体按用途/区域分配，远景过滤避免像素纹理闪烁。
- 角色与车体的刚性部件合成骨骼绘制；保留车轮、独立炮塔/炮管、真实炮口。动态目标不因距离剔除而停止更新。
- 弹体池512个；在途投掷物16个、烟雾4团；低配短效池24个，其他画质64个。离开视域不取消有效弹体。
- 弹着灰尘与弹孔各一个实例化池（96/96），合计 2 次 draw call，不随射击次数增长；10 秒寿命到期只回收槽位。
- 方块材质放大过滤为最近邻，采样成本不升反降；AI 战术每 think 只遍历最近威胁表（5 秒剪枝一次），不做全图搜索。
- 固定60Hz模拟，AI约6–8Hz决策，共享流场。HUD10Hz、名字20Hz。30/60/不限渲染使用固定截止时间调度。
- 低配无MSAA，内部比例上限0.65并限制在1280×720内；HUD原生分辨率。默认不用SSAO、SSR、级联实时阴影或完整刚体/ragdoll。

## 数据解释

`audit-2026-11-06/maps.json` 是五张地图12v12出生视角的单帧快照，不能当作23人同时近战的性能。`performance.json` 是正式四图各8v8/12v12、每段60秒的固定目标B路线，保留AI、遇敌、死亡和复活；种子1106，未开启lite。

采样分别记录真实渲染帧间隔、模拟步CPU、渲染提交CPU、calls/三角形分布和JS堆。音频未主动解锁，没有GPU timer。`simulationOverload`非零时不能声称模拟维持实时；累加器最多追赶30步，超额负载有明确计数。

`near-combat.json` 是另一个受控专项：23名角色放入近战区域、提高生命保留持续交火、统一争夺B点，正常感知/移动/射击/弹道，固定观察相机，逐帧检查投影视域人数。不能代替真实玩家第一人称网络激战。

100次换枪与100次尸体GPU循环见 `lifecycle.json`；属于函数级压力，不能代替三局进程工作集或100次完整联网重生。

## 仍需目标机验收

J1900系统、浏览器、驱动与硬件WebGL2；四图冷/热加载；8v8/12v12房主/客机与23人近战；连续三局的内存；50/100ms RTT、抖动和丢包；全部车型坡路和多人车战。

建议预算仍为帧间隔中位33.3ms、p95≤40ms、典型≤150 calls、激战≤250 calls。这里只报告实际采样，不将建议预算写成目标机已达标。

## 23人近战压力专项

当前版本连续60秒保留24实体，23名AI全程存活且逐帧投影可见人数23–23，共产生3450个弹体；没有关闭AI/感知/移动/射击/弹道。为稳定测试区域，加入可见、碰撞和射线一致的60×60m临时围场；观察相机为俯视。提高生命只用于保留同时交火，不能把此数据当真实玩家第一人称网络对战成绩。

1800帧，帧间隔中位33.3ms、p95 35.2ms；模拟步p95 0.8ms、渲染提交p95 2.2ms；calls中位110、最大114，三角形最大37392，模拟超载0。原始数据见 `near-combat.json`，截图见 `screenshots/near-combat-23.png`。前期开放区域的AI追击会离开相机范围，相关记录保留但不计通过。
