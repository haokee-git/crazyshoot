# AI 战术决策与退化约束

这套决策覆盖步兵、装甲和火控。它使用现有的导航、碰撞、武器伤害及补给机制，比较当前行动的收益和风险；没有给断桥写固定的“先 C 再 B”脚本。

## 决策分层

1. **感知与记忆**：目标必须先通过距离、视角及遮挡检查。队友共享实际观察到的位置，装甲按车辆去重；战略判断不追踪墙后敌人的实时坐标。目标运动由连续观察估计。报告随时间衰减，过期后不再形成即时威胁。
2. **战场目标**：比较控制点价值、地图中部价值、己方分工、已观察到的压力、支援、近期损失、不可达记忆和车况。己方据点也能被选中，但需要防守价值；距离近本身不足以让装甲无限留守。残血、缺弹时允许返回基地。
3. **局部交战**：步兵在推进、突击、侧击、架枪、脱离和重新接敌之间比较效用。角色与武器决定合适距离，人数优势、受压制程度、掩体、弹药和目标装甲影响选择。
4. **执行**：导航与实际运动仍来自同一份体素和碰撞查询。局部位置必须有支撑、能容纳角色、没有水体或实体占用；车辆转弯、坡度和安全碰撞检查保留。跟车等待有边界，长期停车的友军可以触发包含友车占用的绕行规划。
5. **火控**：比较可见目标价值，保留合理目标以减少无意义换靶；使用观察速度估计提前量与已有弹道补偿。步兵根据距离、武器、运动、受压和弹药决定连发长度、间隔及散布。只露出头部时才能改瞄露出部分。普通步枪/机枪不对封闭装甲乘员浪费子弹；炮手选择 AP/HE 并遵守真实炮口方向、武器射速和装填。

## 行为约束

| 局势变化 | 决策变化 | 必须保持的约束 |
| --- | --- | --- |
| 开局家点已有队友，前线尚未接敌 | 倾向让坦克及部分部队争夺中线，另一些单位承担近点与支援 | 不把任何地图点 ID 写成固定开局任务 |
| 同一己方据点遭到观察到的入侵 | 可从进攻改为回防，按友军力量和已分配任务分担 | 不使用未观察敌人的实时位置 |
| 长枪有合适射距与射界 | 架枪或转移到有利位置 | 反应时间、枪口与弹道约束不变 |
| 长枪被近距离压迫 | 后撤/换角度，寻找更合适射距 | 不瞬移，不无视碰撞 |
| 步兵残血或受压时换弹 | 退向可用掩体，安全后重新接战 | 已经藏在有效掩体后时允许低姿态停留 |
| 弹药彻底耗尽或严重受伤 | 脱离战斗，必要时返回基地补给 | 在补给位置允许有目的的等待，不能被当作寻路卡死 |
| 友军挡住枪线 | 暂停开火，考虑更换射击角度 | 不通过队友射击，不用无效射击伪装压制 |
| 载具残血/缺弹 | 以恢复战斗力为目标；补到合理状态后再出击 | 补给只来自实际补给机制 |
| 前车临时占点/转向 | 保持车距跟随 | 接近静止时释放刹车，不能自动变成倒车 |
| 前车长期停留而后车另有任务 | 检查安全绕行 | 规划使用同一车辆占用查询，额外占用信息只来自友车；实际物理仍检查所有车辆 |
| 坦克获得近距离有效射击机会 | 稳住车体交战 | 没有射界、被友车挡枪或需要撤回补给时不能无限停车 |

## 防止机械与反复横跳

- 先比较全部可行策略，不用单个条件把整局锁成一种行动。
- 小幅效用变化不打断已有行动；重大威胁、任务完成和资源危机可以触发改变。
- 战略任务保持足够时间完成一个动作，局部避让和瞄准仍按自己的频率更新。
- 决策不绕开执行层。不能到达的位置由真实支撑、导航和碰撞否决；不能命中的目标由真实射界和武器规则否决。
- 大房间保留共享目标与决策频率预算，驾驶与炮手不能降到不够驾驶的低频。

## 验收方式

- 使用 0.20.9 的冻结生产包作为对照，而不是凭新代码的分支数量评价 AI。
- 固定四张图、相同随机种子和 40 人规模，记录占点、战斗伤害、击杀、发射数、载具到点、长时间无法推进及模拟耗时。双方总量用于评估对局活动，不把单个随机种子的胜负当成强弱结论。
- 卡住检测看实际导航目的地，排除已经抵达的补给/架枪目的地；保留逐次卡住记录供定位，不能把正常掩体换弹当卡死，也不能排除真正的无路径停滞。
- 单独验证“同一地点不同局势作出不同选择”，以及友军挡枪后是否真的停火、换弹后是否真的能移动。
- 断桥 C 坡两车拥堵、桥上存在敌坦克及自然开局继续作为物理推进专项，不能仅靠全局平均值掩盖旧问题复发。
- 数据与未通过的中间结果保存在 `docs/audit-2026-11-13-tactical-brain/`。这些是确定性回归样本，不代替长期真人对局统计。
