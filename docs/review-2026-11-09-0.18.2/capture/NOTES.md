# 花园 B · 站在广场石面占点（据点半高差）

对应修复：**占点判定改为「按脚下的地面」**，而不是「围绕圆心的绝对高度窗口」（`engine.ts` `updateCapture` 里的 `standingIn`）。
花园 B 的圆环跨一个 3m 台阶：喷泉盆地 `ring.y = 5.08`，广场石面 `8–9m`。旧逻辑用圆心高度 ±窗口判站人，站在广场上永远算「不在圈内」；新逻辑取脚下 `supportAt`，水平在圈内且脚离地面 ≤1.2m 就算。

## 复现方式（脚本）

`/tmp/rev_capture.mjs`：`forceStart()` → `cancelAnimationFrame(g.raf)` → 传送到点位 → 手动 `g.simulationNow += 1000/60; g.simulate(1/60)` ×540 → `g.presentation.render(...)` + `g.callbacks.onHud(g.hudState(...))` → 截图。每点截图前把 B 重置为未占领。
