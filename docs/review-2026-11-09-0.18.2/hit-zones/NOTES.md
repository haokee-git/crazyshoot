# 命中区（hit-zones）示意：旧"大腿算躯干" vs 新"大腿=limb"

> 这是**示意图**（Playwright 打开本地 HTML/CSS 绘制），不是游戏截图；用来说明倍率分区，数值来自 0.18.2 本地构建的 `hit-zones.ts`。

![命中区前后对比](hit-zones-before-after.png)（1280×720）

## 图怎么看

| 颜色 | 部位 | 倍率 |
| --- | --- | --- |
| 红 | 头 | **2.2×** |
| 绿 | 躯干（**胯以上**，模型高度 ratio 0.5） | 1.0× |
| 橙 | 大腿 / 膝 / 小腿 / 脚 / 手臂 | 非 SMG **0.7×**；SMG 与躯干同为 **1.0×** |

## 两条结论

1. **旧**：躯干判定一直画到膝盖上方，"打大腿"按躯干 1.0× 结算 → 命中伤害偏高、TTK 偏短（左栏绿腿）。
2. **新（0.18.2）**：躯干只取胯部以上，大腿/膝/小腿/脚/手臂全部按 limb 0.7×（右栏橙腿）；SMG 因为 limb=torso=1.0×，所以冲锋枪打腿不吃亏。

## 备注

- 躯干"只算胯以上"是用模型高度比例 0.5 切的，不是按骨骼节点；趴下/蹲下时仍然按当前姿态的躯干包围盒算。
- 如果只看一张图：右栏（新）里**大腿是橙色**、**胯线在躯干下沿**，就是这次修复的全部视觉差别。
