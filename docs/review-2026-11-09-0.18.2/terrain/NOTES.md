## 结论先说

不是把整张地图抬高，也不是把断崖填成一个大平台；而是**只在据点圆环（r=12m）内**把地形整平到圆心高度，圆环外再用一段 12–16m 的**台阶缓坡**接回原地形。

- 断桥 A（北收费站）：原来圆心和北半圈在 **+8m** 台地上，南半圈（朝桥方向）是 0–1m。整平后**圈内 7–8m（高差 1m）**，旧断崖被推到圈外的 z≈171–183 台阶坡上。
- 断桥 C（南磨坊）：原圈内 0–6m，整平后**圈内 5–6m（高差 1m）**，南侧朝河的陡坡仍在圈外（z≈120–129）。
- 其它地图：docks / garden / airfield 的据点圈内原本高差 ≤1m，**没有整平**；花园 B 因为有喷泉盆地跳过。
- 占领判定本身已经不依赖圆心绝对高度：站在圈内、脚踩圈内地面（±1.2m）就算。所以即使以后不整平，低半圈也能占点（这是第一层修复）；整平是第二层“别让圈里有断崖”的修复。

## 算法（`voxel-map-data.ts`）

```ts
// 对每个据点：若圈内 base 地形高差 > 1.5m
//   target = 圆心高度
//   blend  = max(8, min(20, 2 * 高差))     // A:16m, C:12m
//   d <= r        : h = target
//   r < d < r+blend: h = lerp(地形, target, 1-smooth(r, r+blend, d))
```

- 采样 r=12 圈内 `battlefieldHeight`，高差 ≤1.5m 的据点不动（docks/garden/airfield 全部跳过）。
- 带喷泉盆地的据点跳过（花园 B），否则会把水池填平；花园 B 改用“地面相对”占领逻辑解决。
- 桥面上 B 点不受影响（桥面是后置 box，不参与地形整平）。
- 只改高度，不动材质/道路/建筑：道路、建筑、掩体随后按新高度落位。

## 代价与可选方案

现在的视觉代价是：A 变成一座 **8m 高的台地/阶梯坡**，C 变成 **6m 高的石阶挡土台**（见上图）。它们都在圈外 12–16m 内收坡，圈内是平的。

如果觉得台地视觉太重，下一步可以选：
1. **不整平，只保留地面相对占领**：圈内低半圈也能占，但圆环会铺在坡上（视觉上环会倾斜），旧断崖仍在圈内。
2. **把 A 整平到低处**（例如 3–5m）：台地变矮，但会削掉设计上的“北岸收费平台/狙击位”（原设计高度 8m）。
3. **缩短缓坡**（blend 8–10m）：圈内仍平，但外侧坡更陡、台阶更密。

当前 0.18.2 交付的是方案“整平到圆心高度 + 12–16m 缓坡”，建议先按这个审；要改的话告诉我选哪个方案，我再出一版并重新发布。
