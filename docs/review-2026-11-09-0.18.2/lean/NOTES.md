# 歪头：上半身圆弧平移，无滚转，准星居中（0.18.2 实机）

机位：断桥 **A 高地旁桥面**（133,143），面朝北偏右贴着石护墙（yaw −0.4）。左/右手边是近处石砌护墙，正前方是树篱、白房子与砖房——近墙纹理随身体横移滑动，远处建筑位移小，能直接看出是**镜头平移**而不是滚转。

## 动图

| 文件 | 内容 | 规格 |
| --- | --- | --- |
| `hip-lean.gif` | 腰射：站立 → 满左倾 → 回正 → 满右倾 → 回正，四段各约 0.6s，另有首尾各 0.3s 站立 | 12 fps / 3.0s / 880×495 |

看点：
- 枪身、准星全程**不滚转**（`viewmodel.group.rotation.z = 0`），画面里准星/镜片中心始终在屏幕正中；世界横向平移来自相机眼点横移 ≈0.205m。
- 走向左墙/右墙时，近处石墙纹理会明显滑动，而远处房子的位移很小——这是平移造成的视差，不是旋转。

## 实测数据（`lean-stats.json`）

- 满左倾相机：(132.811, 3.614, 142.920)；满右倾：(133.189, 3.614, 143.080)；站立：(133.000, 3.650, 143.000)。
- 横向位移 = **0.205m（相机侧向量；x 分量 ±0.189m、z 分量 ±0.080m）**，下沉 0.036m（`LEAN_RADIUS 0.6 × (1−cos20°)`）。
- 三态 `camera.rotation = (pitch, yaw, 0)`，`rotation.z` 恒为 0；`viewmodel.group.rotation.z = 0`、四元数 `[0,0,0,1]`（不滚转）。
- 开镜 `adsBlend = 1.0`，开镜状态 `ads=true`；准星/镜片中心居中由上面的像素测量佐证。

## 抓图方法

本地 dev（`game.html?map=broken_bridge&prep=999&bots=0&res=64`）→ 单人开局 → 取消 rAF → 60Hz 逐帧 `simulate` + `presentation.render`，每 5 帧截一张（12fps），ffmpeg 生成调色板 GIF。脚本在 `/tmp/lean-capture.mjs`。

> 说明：0.18.2 的歪头是**相机眼点平移**，第一人称枪与镜固定在相机上，所以屏幕上枪不横移、只保留世界视差；这与旧版“枪绕前向轴滚转 20°”有本质区别。旧版对照图见 `docs/pixel-lean-2026-11-08/lean-ads-left.png`。
>
