# 严格像素方块、歪头与趴下姿态

2026-11-08，Asia/Shanghai。版本 **0.16.6**。本轮把地图方块贴图改成 Minecraft 式严格像素，加入 Q/E 歪头（含联机同步），并重做蹲/趴的起身与趴下互斥规则。

## 严格像素方块

- 世界方块图集 `DataArrayTexture` 的放大过滤改为 `NearestFilter`，缩小保留 mipmap 以免远处闪烁；静态合批图集与旧地图材质同步修改。
- 每个方块面就是一张 32/64/128 像素网格，近看每个纹素都是棱角分明的纯色正方形，不再有线性放大的糊边。
- 弹孔贴花保持原有的照片式真实形状，仍使用线性过滤，不参与像素化。

## 歪头（Q / E）

- 站立或蹲下时按住 **Q** 向左侧身高、**E** 向右侧身，同时按住等于回正；趴下、疾跑、游泳、攀爬、上下车时不可歪头。
- 镜头不滚转；枪械与手绕前向轴倾斜 **20°**，腰射时整体向侧方平移并轻微下沉。
- 开镜时旋转轴改到镜片视线轴，并额外把枪轴钉在屏幕中心：准星始终在画面正中心，红点仍居中。
- 射击从相机准星射线命中点反向收敛枪口方向，**静止时落点与准星严格一致**（实测三态误差 0.6–2.5 mm，仅受随机散布影响）。
- 歪头状态进入网络快照，客机也能看到；第三人称角色上半身同步倾斜约 29°。

## 蹲 / 趴的姿态规则

- 蹲下或趴下时按 **空格**：先起身（不跳），站起来后再按空格才会跳。起身后需要先松开空格/蹲键才会重新进入低姿态。
- 趴下时「移动」与「开镜/射击」互斥，**先到先得**：先在移动就开不了镜、打不了枪；先开镜或已在射击就推不动。先来者停止后，后来者立刻生效；两者同时按下时移动优先。后来者不会排队补放。
- 蹲下不受此限制，仍可移动射击。

## 实现位置

- `src/game/world/voxel-map-render.ts`、`voxel-arena.ts`、`batch-static.ts`：最近邻放大。
- `src/game/player/stance.ts`：趴下互斥与歪头方向的纯函数。
- `src/game/player/controller.ts`：`lean` 缓动与限制条件。
- `src/game/weapons/viewmodel.ts`：30° 滚转、腰射位移、开镜绕镜片轴与枪轴钉中心。
- `src/game/engine.ts`：空格起身状态机、趴下仲裁、射击收敛、歪头网络同步与第三人称躯干倾斜。
- `tests/stance.test.ts`：互斥与歪头方向单测。

## 已知边界

- 歪头按键固定为 Q/E；靠近可交互物时 E 优先交互，这一次按键不会触发右歪头。
- AI 不会主动歪头（战术动作里没有需求），只影响玩家。
- 未在 J1900 真机验收；本轮只有 macOS Chromium 数据。
