# 赛前整备阶段（20s）

## 流程
1. 地图加载完、所有客户端资源就绪、房主点开始后，进入 **20 秒整备**。
2. 所有玩家在己方出生区生成，**不持武器**；AI 同样在基地待命。
3. 屏幕出现半透明黑色装备页（约 80% 黑，能看见后面的 3D 场景）。
4. 装备页内选择：主武器、瞄具、2 种投掷物；大厅可保留预设，最终确认以整备页为准。
5. 按右上角 **X** 或 **Esc** 关闭装备页，进入场景自由移动；**全图可走，但不持武器、不能开火/ADS/投掷/上车/拾取**。
6. 关闭后可按 **Tab** 重新打开装备页；整备页打开时移动输入暂停。
7. 20 秒结束：装备页自动关闭，**所有玩家统一传送回己方出生点**，随后获得所选主武器/瞄具/投掷物；战斗、据点、计分、载具、特殊武器同时启用。
8. 整备期间据点不可占领、比分和比赛计时不启动；不会因为“跑到点里”提前得分。
9. 死亡后至少 5 秒等待，倒计时结束**手动点击“部署”**才复活；沿用本局已确定的装备，不重新进整备页。

## 画面
- 半透明黑底 + 暗色面板；背景实时 3D 场景可见。
- 顶部：20 秒倒计时、队伍、地图名；右上角 X。
- 左侧：11 把主武器的分类/网格/属性；右侧：瞄具、投掷物、当前配置、确认/关闭提示。
- 低配：不做重模糊/重后期；只做透明度、细线和轻动效。
- 整备页关闭后，HUD 显示“整备中 00:20”与“Tab 装备”。

## 已确认
- 关闭装备页后 **全图自由移动**。
- 20 秒结束 **统一传送回己方出生点**，再装备开战；不保留整备阶段的位置。
